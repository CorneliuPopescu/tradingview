# tradingview

## Pine Script edits: see it on the chart before saying done

After any Pine Script change, take a fresh chart screenshot through the TradingView MCP (`capture_screenshot`; TradingView Desktop must be running with `--remote-debugging-port=9222`, see README). Check every stated visual requirement against that screenshot (label alignment, colour, distance to the ray, current-month levels on each timeframe) and state what the screenshot shows. The spec is not met until it is seen on the chart. Report done only after that check. (RSI P-20260919-1, 2026-09-19)
